Clipper privacy policy

Last updated: 17 November 2026

Who uses Clipper

Clipper is a private desktop tool used only by its owner, on the owner's own computer. It has no other users.

What Google data it accesses

With the owner's permission, Clipper uses the YouTube Data API to upload videos to the owner's own YouTube channel and to set each video's title, description, tags, privacy setting and paid-promotion label. It reads the channel's name once, to confirm which channel it is connected to.

How the data is stored

The sign-in token Google issues is stored only on the owner's computer. Clipper has no server, and it does not send Google user data to any other party.

What is not done

Clipper does not collect, sell or share personal data. It does not access other people's YouTube accounts or data, and it does not use Google user data for advertising.

Clipper's use of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.

Removing access

The owner can remove Clipper's access at any time at myaccount.google.com/permissions. Deleting the local token file also ends access.
